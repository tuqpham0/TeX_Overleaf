# UF GMA LaTeX introduction
This is a collection of documents to introduce students to LaTeX. Some features presented are specifically based off Overleaf, but I have tried to highlight them.

## Use case
I guess I wrote this with the intention that you can read along through the PDF mostly, referring to the file structure when prompted to by the PDF. To present from this, you can maybe present directly from the document, or perhaps summarize the important bits. I have tried to layout some proper TeX practices and philosophy in how a TeX document shuold be wwritten for good legibility.

If you are a better TeX user than I am, feel free to fork and improve on the files.
